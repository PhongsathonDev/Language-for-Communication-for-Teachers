## 📖 เกี่ยวกับโปรเจกต์ (Overview)

เว็บแอปพลิเคชันสรุปบทเรียน สื่อการสอนแบบมีปฏิสัมพันธ์ (Interactive Learning Platform) และคลังข้อสอบวิชา **020033401 ภาษาเพื่อการสื่อสารสำหรับครู (Language for Communication for Teachers)** คณะครุศาสตร์อุตสาหกรรม มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (KMUTNB)  
เนื้อหาครอบคลุมครบถ้วน 100% ตามเอกสารประกอบการสอนทั้ง ๘ หน่วยการเรียนรู้ของ **รองศาสตราจารย์ ดร.พรวิไล สุขมาก** ออกแบบมาเป็นพิเศษเพื่อช่วยให้นักศึกษาครูและผู้สนใจสามารถศึกษา ทำความเข้าใจหลักภาษาศาสตร์ ทักษะการฟัง พูด อ่าน เขียน และการสื่อสารในวิชาชีพครูได้อย่างลึกซึ้งและมีประสิทธิภาพ

## ✨ ฟีเจอร์หลัก (Key Features)

### 1. 📚 สรุปเนื้อหาเจาะลึก ๘ หน่วยการเรียนรู้ (8 Comprehensive Modules)
เนื้อหาสรุปละเอียด มีตารางเปรียบเทียบ แผนผังกระบวนการ และตัวอย่างการใช้งานจริงในบริบทวิชาชีพครู:
- **Module 01: ความสำคัญของภาษากับการสื่อสาร** — นิยามและขอบเขตภาษา, ความสำคัญ 5 มิติ (วัฒนธรรม, สมบัติสังคม, เครื่องมือสื่อสาร, พัฒนามนุษย์, ศาสตร์และศิลป์), กระบวนการสื่อสาร (SMCRF Model) และการวิเคราะห์ปัญหาการใช้ภาษาไทย 4 ด้าน
- **Module 02: ความรู้ทั่วไปเกี่ยวกับการสื่อสารด้วยภาษาไทย** — วัจนภาษา vs อวัจนภาษา 11 ประเภท (สัมผัส, อาการ, วัตถุ, เทศภาษา, กาลภาษา, ปริภาษา, เนตรภาษา ฯลฯ), 17 ลักษณะเฉพาะที่โดดเด่นของภาษาไทย, ระบบเสียง/อักษร/วรรณยุกต์, 3 ระดับภาษา (แบบแผน, กึ่งแบบแผน, กันเอง), คลังลักษณนามเฉพาะทาง และคลินิกคู่คำมักเขียนผิด
- **Module 03: ทักษะการฟัง (Listening Skills)** — การเปรียบเทียบการฟัง (Listening) vs การได้ยิน (Hearing), จุดมุ่งหมายการฟัง 6 มิติ, กระบวนการฟัง 5 ขั้นตอน (Receiving $\rightarrow$ Attending $\rightarrow$ Understanding $\rightarrow$ Evaluating $\rightarrow$ Responding), อุปสรรคและมารยาทการฟังที่ดี
- **Module 04: ทักษะการพูด (Speaking Skills)** — ความสำคัญและสำนวนไทยเกี่ยวกับการพูด, องค์ประกอบ 5 ประการ, 4 ประเภทการพูด (Impromptu, Extemporaneous, Manuscript, Memorized), 5 ขั้นตอนการเตรียมการพูดอย่างมืออาชีพ และศิลปะการใช้น้ำเสียง/ภาษากายของครูในชั้นเรียน
- **Module 05: ทักษะการอ่าน (Reading Skills)** — ความสำคัญและจุดมุ่งหมาย, การเปรียบเทียบการอ่านออกเสียง vs การอ่านในใจ, ลำดับขั้นการอ่าน 4 ระดับ (Literal $\rightarrow$ Interpretive $\rightarrow$ Critical $\rightarrow$ Evaluative), ข้อบกพร่องที่พบบ่อยในการอ่าน และสุขนิสัยที่ดี
- **Module 06: การอ่านจับใจความสำคัญ (Reading for Main Idea)** — โครงสร้างใจความสำคัญ vs พลความ, 5 ตำแหน่งของใจความสำคัญในย่อหน้า (ตอนต้น, ตอนท้าย, ตรงกลาง, ทั้งต้นและท้าย, แฝงอยู่ทั่วทั้งย่อหน้า), เทคนิคการตั้งคำถาม 5W1H และ 4 ขั้นตอนการอ่านจับประเด็น
- **Module 07: ทักษะการเขียน (Writing Skills)** — 5 จุดมุ่งหมายของการเขียน, 3 เสาหลักของงานเขียนที่ดี (**เอกภาพ, สัมพันธภาพ, สารัตถภาพ**), 4 ขั้นตอนกระบวนการเขียน (Prewriting $\rightarrow$ Drafting $\rightarrow$ Revising/Editing $\rightarrow$ Publishing) และจรรยาบรรณของนักเขียน
- **Module 08: การเขียนสรุปความ (Writing Summaries)** — ความหมายและประโยชน์, การสรุปความจากการฟัง vs จากการอ่าน, 4 ขั้นตอนการสรุปความ, 5 กฎเหล็กด้านการใช้ภาษา (ประโยคความเดียว, ข้อห้ามใช้อักษรย่อ, การคงคำราชาศัพท์) และข้อควรระวังเรื่องการห้ามใส่ความเห็นส่วนตัว

### 2. 🛠️ เครื่องมือจำลองและการวิเคราะห์แบบ Interactive
- 🎯 **Main Idea & Supporting Details Analyzer (เครื่องมือฝึกวิเคราะห์ใจความสำคัญ):** จำลองข้อความย่อหน้าจริงทั้ง 5 ตำแหน่ง (ต้น, ท้าย, กลาง, ต้นและท้าย, แฝงอยู่) ให้ผู้เรียนคลิกเลือกประโยคใจความสำคัญ พร้อมตรวจคำตอบและแสดงบทวิเคราะห์โครงสร้างภาษาศาสตร์แบบละเอียด
- 👨‍🏫 **Teacher Communication Simulator (เครื่องมือจำลองสถานการณ์การสื่อสารของครู):** จำลองบทบาทสมมติของครูในการสื่อสารกับ นักเรียน, ผู้ปกครอง และผู้บริหารสถานศึกษา เพื่อประเมินการเลือกใช้วัจนภาษา (ระดับภาษา) ควบคู่กับอวัจนภาษา (น้ำเสียง ท่าทาง เทศภาษา) ในสถานการณ์ต่างๆ
- 🇹🇭 **Thai Linguistics Matrix & Word Clinic (เครื่องมือวิเคราะห์โครงสร้างภาษาไทย):**
  - ตารางระบบเสียงและอักษรไทย (พยัญชนะ ๔๔ รูป ๒๑ เสียง, สระ ๒๑ รูป ๓๒ เสียง, วรรณยุกต์ ๔ รูป ๕ เสียง)
  - คลินิกคำถูก-คำผิด คำที่มักเขียนผิดบ่อยในแวดวงการศึกษา
  - คลังลักษณนามเฉพาะทาง (ขลุ่ย-เลา, เลื่อย-ปื้น, แห-ปาก, พระภิกษุ-รูป ฯลฯ)
- 🎴 **Interactive Flashcards (Active Recall):** การ์ดคำศัพท์ นิยามหลัก กฎเกณฑ์ทางภาษา และคีย์เวิร์ดสำคัญ แยกตามหมวดหมู่ ๘ หน่วยการเรียนรู้
- 📝 **Exam & Practice Quiz Bank (คลังข้อสอบ ๕๐ ข้อ):** แบบทดสอบครอบคลุมทุกหน่วย รองรับทั้งโหมดฝึกฝน (Practice พร้อมเฉลยทันที) และโหมดสอบจริง (Exam จับเวลา บันทึกสถิติ และระบบ Confetti)

## 🚀 การติดตั้งและรันในเครื่อง (Local Development)

หากต้องการรันโปรเจกต์นี้ในเครื่องคอมพิวเตอร์ของคุณ:

### 1. โคลนคลังโค้ด (Clone Repository)
```bash
git clone https://github.com/phongsathondev/Language-for-Communication-for-Teachers.git
cd Language-for-Communication-for-Teachers
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. รันเซิร์ฟเวอร์สำหรับทดสอบ (Development Server)
```bash
npm run dev
```
เปิดบราวเซอร์ไปที่ `http://localhost:5173` หรือพอร์ตที่แสดงในหน้าต่างเทอร์มินัล

### 4. Build เพื่อใช้งานจริง (Production Build)
```bash
npm run build
```
